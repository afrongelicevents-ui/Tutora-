## Lesson room

| #   | Decision                                                                                                                                                                                                                                                                                                    | Why                                       |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| D20 | **The call goes directly between phones** (WebRTC). The two phones find each other by exchanging a few setup messages through the database, which costs a few requests a minute. A dedicated always-on room server ("Durable Object") would need a second Cloudflare app, and so a more complicated deploy. | Simple deploy, $0. Can be upgraded later. |
| D21 | **Audio only by default**, capped at about 24 kbps (roughly 11–20 MB per hour). Video is a button and is capped at 360p and about 300 kbps. Screen share is also a button. The whiteboard, chat and file messages travel inside the call, so they don't touch the server.                                   | Brief: low data.                          |
| D22 | **If a direct connection fails** (some mobile networks block it), the call can be relayed through Cloudflare's TURN service, but only once a TURN key is added (optional, free tier). Without it, most calls still connect directly.                                                                        | Avoids another account on day 1.          |
| D23 | **Group calls connect every phone to every other phone** (fine for up to about 4 people). A Cloudflare SFU can replace this later for bigger groups.                                                                                                                                                        | Simple.                                   |
