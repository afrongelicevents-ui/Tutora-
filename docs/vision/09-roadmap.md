# 09 · Roadmap: seven phases

Sizes: **S** = days, **M** = one to two weeks, **L** = several weeks (rough, for one developer). Every phase keeps the **live site on real data only**; new features are tried on the **test site** (`tutora-test`, fake data, D55) first.

Running-cost impact uses the limits in `10-technical-recommendation.md` (checked 12 Nov 2026).
